# 1.0.4 Hangeul

Compatibility improvements for some quantized models, including selected
FP8/INT8 and ComfyUI-GGUF paths used with regional character LoRAs.

일부 양자화 모델 호환성을 개선했습니다.

Supported files and behavior depend on the model, loader, ComfyUI version and
GPU. This release does not promise support for every quantized model or faster
execution. ComfyUI-GGUF must be installed separately when using GGUF models.

See [quantization compatibility](quantization-compatibility.md) and
[GGUF setup and verified scope](gguf-compatibility.md) for details.
