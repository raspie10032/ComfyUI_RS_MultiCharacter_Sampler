# 1.1.13 Hangeul

Open the 3D pose editor from **RS 3D Pose Masks** and choose **Adult**, **Teen** or **Child** in **Body type** for each person. The presets adjust head, shoulder and limb proportions and joint positions. Height and body width remain adjustable. Saved scenes carry each person's selection into the pose image and numbered masks. Existing skinned scenes open with Adult proportions by default.

**Image → 3D** fits the Adult rig. If you change the body type on a fitted person, the editor clears that person's source-image crop.

## 한국어

**RS 3D 포즈 마스크**의 3D 편집기에서 인물마다 **체형 → 성인 / 청소년 / 어린이**를 선택할 수 있습니다. 체형에 따라 머리와 어깨 비율, 팔·다리 길이, 관절 위치가 달라지며 키와 몸통 너비도 조절할 수 있습니다. 선택한 체형은 장면에 저장되고 포즈 이미지와 인물별 마스크에 반영됩니다.

**이미지 → 3D**는 성인 리그로 맞춥니다. 이후 체형을 바꾸면 해당 인물의 원본 이미지 자르기 범위가 해제됩니다.
