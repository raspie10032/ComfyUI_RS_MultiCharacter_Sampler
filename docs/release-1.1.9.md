# 1.1.9 Hangeul

Workflows that use **NAI Camera Control** from RS NAI API Request 2.9.3 can place
it anywhere in the shared character-building chain. Finalize applies the NAI
camera's view filter, framing-based detail tags and layout settings together.
The shared **RS Camera Control** node also uses the NAI camera's prompt
processing when a native NAI context is connected.

**한국어:** RS NAI API Request 2.9.3의 **NAI 카메라 시점**을 공유 조립 파이프
어디에 연결해도 Finalize에서 시점 필터와 구도별 태그 보강을 적용합니다. 공용
**RS Camera Control**에서도 NAI 컨텍스트가 연결되면 같은 처리를 적용합니다.
