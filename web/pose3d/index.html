RS 3D Pose Masks

Arrange mannequins to create character masks. A composition guide, not exact pose enforcement.

One person's image → automatic estimate → 3D. In group scenes, replaces the selected person only.

Only the source image frame is output; off-frame body parts are excluded. First use downloads SAM 3D Body (2.83 GB).
